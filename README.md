# Base-de-Datos-Sistema-de-Administraci-n-Excavaciones-CEHE
Proyecto Universitario:  se desarrolla una base de datos  en Oracle  para la empresa Excavaciones CEHE, organización dedicada a los movimientos de tierra, excavaciones y apoyo a proyectos de construcción. Su propósito principal es centralizar, organizar y proteger toda la información operativa y administrativa de la empresa.
